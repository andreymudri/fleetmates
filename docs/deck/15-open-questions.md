# 15 · Open questions

Status labels as in [02-domain.md](02-domain.md). Everything in this file is **Open**: it needs an owner decision. Every item has a default that is safe to build, so no item blocks work unless the Milestone column says "before start".

How to use it:

- Section 1 has the owner-level questions. They cut across docs, and most of them come from gaps in the design conversation (answers that were never recorded, or topics the owner deferred). Each one links to the detailed IDs.
- Section 2 says which items gate which milestone.
- Section 3 is the full register. The doc that owns an ID keeps its full discussion; this table is the index.
- To close an item: record the answer in [14-decisions.md](14-decisions.md) as a new D entry, update the owning doc (change **Open** to **Decided**), and delete the row here.
