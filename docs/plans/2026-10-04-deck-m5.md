## Shapes

Every task that produces or consumes these uses them exactly.

- `GET /api/vault/graph?tags=a,b&status=&folder=&maxNodes=`: 200 with the contract 1.11 `VaultGraph` (`nodes[] { id,
  title, tipo, status, tags, area, domain, in_degree, out_degree, mtime_ms }`, `edges[] { source, target }`, optional
  `broken[]`, `truncated`, `counts { notes, edges, orphans, broken }`). 501 `vault_tool_missing` with
  `details.tool: 'vault_graph'`; 503 `vault_unavailable`; 502 `vault_error` (`details.tool`, `details.text` verbatim).
- `GET /api/vault/list?folder=&tags=&tipo=`: `{ notes: NoteRef[] }`, `NoteRef = { path, title, tipo, status, tags,
  domain }` (`domain` = `<d>` for `02-wiki/<d>/...`, else null).
- `GET /api/vault/note?path=`: `{ note: { path, title, frontmatter, body, truncated, total }, backlinks: NoteRef[],
  linksOut: NoteRef[], usage: { citedIn: [{ threadId, title, at }], readBy: [{ sessionId, repoId, repoName, at, tool
  }] } }`; `vault_error` with the `note not found` text verbatim.
- `GET /api/vault/search?q=&limit=` (limit default 5, max 20): `{ hits: [{ path, title, line, snippet, viaGraph }] }`.
- `GET /api/vault/captures?day=YYYY-MM-DD` (default today, local time): `{ day, captures: Capture[] }`, `Capture = {
  path, title, domain, capturedAt, via: 'vault_learn'|'frontmatter', sessionId, repoId, repoName, opened }`.
- `GET /api/misses`: `{ misses: Miss[], unresolved }`, `Miss = { id, question, threadId, searchedTerms,
  createdAt, resolvedBy }`. `POST /api/misses/:id/resolve` `{ resolvedBy: 'dismissed' | 'note:<path>' }`: `{ miss
  }`; `not_found`, `validation_failed`.
- `POST /api/ask` `{ threadId?, text, scope? }`: scope `vault` (default) answers 202 `{ thread: AskThread,
  userMessage: AskMessage, assistantMessageId }`; errors `validation_failed` (empty text, text over 4,000 characters,
  unknown key), `not_found` (unknown `threadId`), `vault_unavailable` (503, retryable), `ask_in_progress` (409). Scope
  `meeting:<id>` is unchanged from M4.
- `POST /api/ask/:messageId/cancel`: 202 `{ messageId }`; `not_found`; `invalid_state` (already finished). A
  meeting-scope message keeps its M4 behaviour.
- `GET /api/threads?limit=` (default 30): `{ threads: AskThread[] }` newest first, vault scope only.
  `GET /api/threads/:id`: `{ thread, messages: AskMessage[] }`. `DELETE /api/threads/:id`: `{ deleted: true }`.
- `AskThread = { id, title, scope, createdAt, updatedAt }`; `AskMessage = { id, threadId, role, text, citations: [{
  path, line, viaGraph }], generalKnowledge, isMiss, status: 'complete'|'cancelled'|'error', error, unverified,
  droppedCitations, createdAt }` (`unverified` true when the answer had no valid `deck-answer` block).
- `GET /api/sessions/:id/memory`: `{ related: [{ path, title, line, snippet }] | null, relatedError: ApiError | null,
  read: [{ path, at }], learned: [{ path, title, at }] }` (`related` = `vault_search` on the session task, top 3;
  `read` and `learned` come from the deck DB and still return while vault-mcp is down).
- WebSocket: `ask.delta { threadId, messageId, text }`, `ask.done { threadId, message }`, `ask.error { threadId,
  messageId, error }`, each with `ephemeral: true`; `misses.changed { unresolved, ephemeral: true }`; the existing
  `health.changed` for `dep: 'vault-mcp'` gains `version` (string or null) and `capabilities` (`string[]`, from
  `graph`, `structured`, `preview`). The session view gains `learnedToday` (count of observed `vault_learn` calls of
  that session since local midnight).
- The `GET /api/version`-adjacent snapshot `recap` gains `chartsAdded` (captures of today, or null while vault-mcp is
  down).

## Destination

The deck asks the owner's Obsidian vault and shows it as a graph, through vault-mcp only. The server holds one
long-lived vault-mcp child with its own small MCP client, health machine and capability detection, the text parsers for
vault-mcp 0.3.0, and the `vault_graph` path for 0.4.0; the Ask engine runs `claude -p --restricted` with the four vault
read tools only, streams the answer, validates its citations, keeps threads and misses in SQLite (migration 0006), and
never writes to the vault; hooks feed note reads and learn calls. The browser shows Memory (clustered and local
graph, Ask panel with History and New thread, note panel with backlinks, links out and "Recently used", Browse by
MOC, Captures and Misses), the palette Memory group and `?` ask, the Focus Memory tab, Home Calm "Charts added" and
"Unanswered questions" and the recap chart segment, and the vault-mcp degraded card. A meeting that rises to
confidential is scrubbed from the pre-migration backups too, and `fleetmates-deck export-misses` writes the golden
query candidates. Automated suites cover exit criteria 1 (vault-mcp 0.4.0 published by the owner and pinned), 2 and 3 (measured
against the pinned 0.4.0) of `docs/deck/12-milestones.md` section 7; criteria 4 (two weeks of real misses), 5 (20 real
questions) and the KB-O1 check need the owner and are recorded as pending in `docs/deck/m5-exit.md`.
