# fleetmates deck M1 (Observe) Implementation Plan

Source: `docs/deck/12-milestones.md` sections 3 and 10.2, the M0 handoff in
`docs/deck/spikes/m0.md` sections 6, 7 and 9, and the screen, API, storage, security,
operations and testing specs linked by section 3. Each task owns its tests.

## Destination

An installed deck observes plain Claude Code sessions through user-level async hooks,
persists and displays their state after a server restart, shows open requests and accurate
counts, and notifies the owner when attention is needed. The Home, palette, read-only Focus,
drawer, First run and Settings screens satisfy their M1 acceptance criteria. The automated
security, fixture, setup, accessibility and performance checks pass. The public release is
prepared with package, CI, documentation and a clean-install rehearsal. The one-week dogfood
criterion and publication require owner activity after the code is ready; record their results
before declaring the milestone complete.

## Global Constraints

- Root package runtime and development dependencies remain zero. Hub dependencies stay in
  `hub/package.json` and its lockfile.
- Node >= 24.2.0. Use built-in `node:sqlite`, `node:http` and ESM `.mjs` for the server.
- Hub socket tests use `TMPDIR=/tmp/hx` or a comparably short path. Tests use fake Claude Code
  and temporary HOME, XDG and runtime directories, never the owner's live settings or services.
- The pinned Claude Code fixture version is 2.1.282. Do not recapture real fixtures without
  the owner's separate authorization. Version drift is reported and does not mutate state.
- The web server binds IPv4 loopback only. Every `/api/*` request and WebSocket upgrade requires
  the token, Host and Origin checks in `docs/deck/05-api.md` and `docs/deck/08-security.md`.
- Hooks never block Claude Code or write stdout. Persist private state with 0600 files and 0700
  directories. Keep token and hook content out of default logs.
- Each new test must fail for a deliberate mutation of the behavior it claims to cover, then
  pass after restoration. Record the mutation and command in the task result.
- Style: single quotes, two-space indentation, no semicolons, JSDoc for public JS exports.
- Commit messages: one English commitlint line with scope `deck`; no tool attribution.
- Public files use placeholders such as `/home/you`, never real names, usernames, emails or
  home paths. Docs in `docs/deck/` are English plain prose without em dashes.
- Do not edit `fleetmates.gate.json`, any prior plan in `docs/plans/`, or `.fleetmates/` to make
  a check pass. Do not run real Claude Code or publish during automated work.
- A denied tool call is a block: report it immediately rather than waiting silently.

## Out of Scope

- Browser terminal and session launch - these are M2 work.
- Answering requests from the browser - this is M3 work; M1 links to the terminal.
- Meetings, Memory and Research screens - these belong to M4 through M6.
- M0 owner checks and recapture of missing real fixtures - both require owner participation
  and are tracked separately in the M0 report.
