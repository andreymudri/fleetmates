# Cost cuts for fleet runs: implementation plan

Spec: `docs/specs/2026-11-06-cost-cuts-design.md`. Executed inline, one task at a time, in order.

## Global Constraints

- Node >= 24.2.0, zero dependencies (runtime and dev), tests on `node:test`.
- Every new test is verified by mutation: break the covered code, watch it fail, restore it.
- Enforcement invariants hold: no check reads `.fleetmates/`, `aggregateVerdict` is the only
  verdict producer, a pending check counts as FAIL.
- Every guarantee a skill states carries its limit in the same breath (CONTRIBUTING.md).
- The repo is public: no personal names, emails or real home paths anywhere.
- Commit messages: single line, commitlint style, English, no tool attribution.
- `npm test` stays green at the end of every task (baseline 3953 tests, 0 failing, 18 skipped).

## Destination

`finish` reviews a run once, on its integrated diff. The fleet skills load a short core and read
references on demand. An eval re-run shows the fleet arm at least 30% cheaper than 2.8.0, with
the same fail-to-pass result.

## Out of Scope

- Routing to inline by default. It is deferred until this plan is measured.
- Slimming `fleet-supervision` and `finishing-a-development-branch`. They were not loaded in the
  measured runs.
